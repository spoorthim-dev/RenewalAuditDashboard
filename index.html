How to read the Renewal Audit

This dashboard tracks every opportunity expected to renew in 2026, showing whether each has closed, been lost, or is still open — including renewals that closed but were never part of the original forecast.

Forecasted Renewal Close Date

Q1–Q4 CY2026 — when the renewal was expected to close at the time the 2026 forecast was locked (1/16). Renewals that closed/won without ever carrying a forecasted date are shown under the quarter they actually closed in.

Renewal Disposition

Closed/Won — the quarter shown is when it actually closed. Lost — closed lost. Open — still active. Needs Review — status data didn't resolve cleanly and Sales Ops should take a look.

Key metrics

Renewal Rate = (Booking of Planned + Ahead-of-Schedule closes) ÷ Retention Target Forecasted.
$ Deficit = Retention Target Forecasted − all realized bookings (planned + unplanned + ahead).

Questions this dashboard helps answer

• Why is my renewal retention rate off, even if I'm over/under my dollar goal?
• Are there renewals that still need to be created for next year?
• How is a specific DSR grouping trending?
• What's the best-case path to hit a target renewal rate by year close?

Tips

Click any Status Mix pill in the DSR Report breakdown to open the underlying list of opportunities. Use the Strategy tab to set a year-close renewal rate target and see the best-case plan to get there.

This dashboard is a snapshot pulled directly from Salesforce (see the "Data pulled as of" timestamp above), using the same opportunity set and filter logic as the source 2026 Renewal Audit Report. To get a fresh snapshot, ask Claude to regenerate this dashboard.
